# Wiki Schema

The wiki is Becky's compiled knowledge base: plain markdown files with [[wikilinks]], maintained by the [[watcher]] agent. No database, no embeddings (until >500 articles), no special tooling required.

## Structure

```
wiki/
  raw/              Source material — written by agents during work
    briefs/         Product briefs from PM
    prds/           Product requirements documents
    ux-specs/       UX specifications
    architecture/   Architecture docs and ADRs
    implementation-notes/   Dev notes during implementation
    test-reports/   QA test results
    verdicts/       Heimdall verdict files (YAML)
  compiled/         Distilled knowledge — maintained by Watcher
    index.md        Complete categorized index of all articles
    concepts/       Domain knowledge, patterns, conventions
    decisions/      ADRs, technology choices, scope decisions
    incidents/      P0/P1 post-mortems, root cause analyses
```

## Article format

```markdown
---
title: "Article Title"
category: "concepts"          # concepts | decisions | incidents
created: "2026-04-12"
updated: "2026-04-12"
related_rules: ["D-1", "R-1"] # Rule IDs this article references
tags: ["database", "safety"]
---

Article body. Plain markdown. [[Wikilinks]] to related articles.

Keep under 500 words. If longer, split into multiple articles.
```

## Wikilinks

Use Obsidian-style `[[Article Title]]` links. Watcher resolves these to file paths during compilation. If a wikilink target doesn't exist, Watcher creates a stub article.

## Index format

`wiki/compiled/index.md` is auto-generated by Watcher. Format:

```markdown
# Wiki Index

## Concepts
- [[Article A]] — one-line description
- [[Article B]] — one-line description

## Decisions
- [[ADR-001: Why Postgres]] — one-line description

## Incidents
- [[2026-04-05 Folio Zero Incident]] — one-line description

---
Last compiled: 2026-04-12 | Articles: 42 | Rules referenced: 15
```
