Chapter 5

Autopilot, explained

Each phase is self-contained. The agent reads inputs from a known location and writes outputs to a known location — no ambient context needed. So the whole pipeline can run unattended.

You type one command before bed. You wake up to completed work: every phase documented, every decision recorded, every output verified. Manual mode (run → approve) gives you a gate between every phase when you'd rather drive.

Chapter 6

The verdict

Heimdall reports completion in three tiers — and never combines them into one number. This is how Becky kills inflated "done."

DONE

Runtime evidence. An API response, a DB row, a screenshot of the feature actually working against a real database.

VERIFIED

Line-by-line code citation. Every acceptance criterion traced to a file and line that satisfies it.

AUDITED

File exists, LOC counted, function names match. The weakest tier — and never reported as DONE.

“tsc clean + tests pass” is necessary — but it is not DONE. Runtime evidence is.

Chapter 7 · New in v2

Ships clean

Becky carries a built-in privacy guard so your secrets and your personal life never end up in a commit.

SCAN

npm run privacy

One command scans the whole repo for secrets (API keys, tokens, JWTs, private keys) and personal-identity markers. It exits non-zero on any hit — perfect as a pre-commit hook.

YOUR TERMS

A private deny-list

Copy scripts/.privacy-deny.example → scripts/.privacy-deny.local and add your own names. The local file is git-ignored, so your personal terms are never committed — not even to define them.

POLICY

SECURITY.md

The repo ships with a short security & privacy policy: no secrets, no personal data, how to report an issue, and how to wire the scan into your hooks.
